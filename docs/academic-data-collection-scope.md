# 한국외대 정보처 회신 이후 학사자료 이용 범위 (2026-11-23)

**최상위 근거:** [정보처 서면 회신 전문](sources/2026-11-23-hufs-information-office-reply.txt) · [현행 아키텍처 §0](architecture.md). 학교는 한모를 공식 인정·제휴·인증하지 않았으며, 과거 학기 목록/파일/API 별도 제공은 거부했습니다. 운영자가 대면에서 들은 보다 넓은 공개정보 활용 설명은 학교에 재문의하지 않고 개발 결정의 참고로 보존하되, 서면의 명시적인 제한을 해제한 근거로 표기하지 않습니다. [운영자 후속 결정 및 철회 절차](public-data-operating-decision.md)에 **합성 개발 허용과 실자료 연결 보류**를 구분합니다.

| 자료·행동 | 허용 범위 | 금지/보류 |
|---|---|---|
| 공개 학사공지 | 로그인 없는 공개 정보의 최소 안내·원문 링크 | 공지 본문/첨부파일 재게시, 교수명·수강 관련 정보, 학교 대신 학생 적용/자격 판정 |

| 학교 계정/개인 자료 | 수집·대리 로그인 없음 | 학교 계정·학적·개인 성적/수강 원장 취급 금지 |

## 자동 수집의 필수 조건

- 로그인 없는 공개 화면의 노출 URL만 사용; 학사시스템 내부/비노출 주소 호출 금지.
- 학사공지 **1일 1회 이하**, 첫 목록 페이지 + 새 공지 상세 페이지만.
- 강의시간표 **학기당 2회 이하**.
- 요청 사이 최소 **10초**, 동시 연결 **1개**, 실행당 최대 **50건**.
- 수강신청·수강정정 **기간 전체와 각 시작 전·종료 후 1일**에는 수집 금지.
  - **2026 동계 계절학기 신청(운영자 제공):** **11/25~11/27**, **12/1~12/3** 매일 **10:00~16:00 KST**. 실제 크롤링 금지는 시간대만이 아니라 **11/24~11/28, 11/30~12/4 각 날짜 전체(00:00~24:00 KST)**.
  - `data/collection-blackouts.json`과 `scripts/collection-window.mjs`에서 전후 1일을 자동 계산하고 `scripts/check-collection-window.mjs`에서 수집 허용 전 검사. 학교의 **다른 신청/정정 일정 전체가 미확정**이므로 그 밖의 날도 수집 허가로 간주하지 않음. 실제 수집기는 아직 미구현·OFF.
- 한 건이라도 오류 응답/접속 제한이면 **즉시 중단하고 그날 재시도 금지**.
- User-Agent에는 한모 서비스명과 운영자 연락처 포함, 서버 부하를 유발하지 않음.
- 학교의 조건 변경/철회·차단에 즉시 대응. 실제 수집기는 **초기 OFF**이며 규정 준수 테스트·운영자 승인 전 실행하지 않음.

학생 화면의 공식 수강/졸업/마감 정보는 **학교 공식 시스템만 기준**입니다. 학업 데이터 어댑터는 현재 `mode: disabled`이며 기존 Supabase Draft #93은 새 범위에 맞지 않아 재설계 전 활성화하지 않습니다.

**미확정:** “수강 관련 정보”의 세부 필드 범위, 학사일정 자체 구조화, 공지 요약 허용 범위. 서면에서 명시하지 않은 사용은 허용으로 간주하지 않으며 공개·저장·자동 수집을 보류합니다.

## 운영자 후속 선택 · 문의 없이 차별화 기능 개발

PC 웹의 **학사공지 정밀 검색·개설 이력/추세·다중 출처 일정 통합·공식 문의처 검색**은 실제 학교 자료 없이 합성 자료·비식별 더미로 설계·테스트할 수 있습니다. 대면에서 전달된 넓은 취지로 기술 설계가 중단될 필요는 없지만, **학생에게 공개할 실자료 범위는 위 표와 수집 조건을 넘기지 않습니다.** 학교 허용과 운영자 개발 결정은 구분합니다. 요청/철회/정정 시 수집·공개를 즉시 차단하고 캐시·구판까지 처리하는 [런북](public-data-operating-decision.md)과 [구현 게이트 #126](https://github.com/ot4562-glitch/Hanmo_develop/issues/126)을 적용합니다. 실제 자료 연결은 여전히 OFF입니다.
