# 학교 학사자료 수집 범위 · 검토 초안

이 목록은 [학교 자료 이용 허가 확인 이슈 #27](https://github.com/ot4562-glitch/Hanmo_develop/issues/27)의 검토 대상입니다. 승인 전에는 수집·가공·재배포하지 않으며 학생용 학사자료 연결은 `mode: disabled`로 유지합니다.

## 검토 대상

- 학사공지 및 학사일정: 게시 원문, 정정·취소 판본, 적용 캠퍼스·학번·전공·신청자격·신청기간
- 공개 강좌·분반·시간표: 학수번호, 학기, 캠퍼스, 분반 및 시간·강의실·담당교수의 공개 표시 정보
- 적용 학칙·요건: 적용 학년도, 변경 이력, 예외·면제·동일 과목의 승인 근거

학생 계정 로그인, 개인 성적표, 개인 학번 전체, 비공개 수강 이력, 학적 조회를 이 문서에서 수집 대상으로 승인하지 않습니다. 사용자 제공 CSV나 저장 HTML은 브라우저 내 비공식 입력이며 학교의 공식 원본으로 승격하지 않습니다.

## 허용 여부를 확인할 항목

1. 출처별 접근·정기 수집·저장·가공·재배포 허가 조건과 이용 목적을 확인합니다.
2. 공개된 자료라도 최신 판본·정정·취소·적용 대상·열람 권한을 별도로 검증합니다.
3. 자료 출처와 승인 판본을 독립 검수하고 철회·정정·만료 시 학생 화면에서 안전하게 제외합니다.
4. 승인·운영 연결 이전에는 `NOT_CONNECTED` 또는 검토 대기 상태를 유지합니다. 합성 데이터를 실제 학교 자료처럼 대체하지 않습니다.

현행 정책과 실제 구현 상태는 [아키텍처](architecture.md), 자료 운영 세부 절차는 [학사자료 수명주기](academic-data-lifecycle-operations.md), 운영·권한 인계는 [학생 데이터 소스 인계](student-data-source-handoff.md)를 기준으로 합니다. 협의 대상과 미결 사안은 GitHub Issues에서 추적합니다.
