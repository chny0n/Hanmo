# 학사 정보 · 강의 검색

신규 기능 개발은 아래 두 페이지뿐입니다. 운영 한모의 기존 연습 기능과 PC 도구는 신규 구현 범위가 아닙니다.

## 1. 학사 정보

- 공지: 허용·검수된 제목, 게시일, 분야, 캠퍼스, 출처 URL로 정밀 검색 및 필터.
- 검색: 기존 오타·띄어쓰기·약칭 정규화와 문자 2그램 순위 알고리즘을 메타데이터 전용으로 분리했습니다. FAQ·공지 본문 전문·학생별 자격 판정은 포함하지 않습니다.
- 달력: 기존 월간 보기 유지. 허용된 신규 공지에서 검수한 일정 메타데이터 표시만 검토합니다. 학생별 마감·자격 추론이나 별도 달력 크롤러는 대상이 아닙니다.
- 누락, 빈 결과, 오류 및 미연결을 구분합니다. 정정·철회는 내부 관리로 제한하며 학생용 변경 비교 화면은 만들지 않습니다.

## 2. 강의 검색

- 검수된 과목 식별자·강의명·학기·캠퍼스 및 출처로 검색합니다. 불명확한 수강 관련 필드는 공개 전 보류합니다.
- 동일 과목 여부와 관측 범위를 검증한 개설 이력만 사용합니다. 기존 개설 집계 중 같은 계절 최대 4개 학기, 목표 이전 최대 8개 정규 학기의 계산을 복원했습니다.
- 완전 목록과 검증된 동일 과목의 개설 여부만 분모에 포함합니다. 부분 목록·미확인 학기는 미개설로 추정하지 않습니다. 과거 횟수는 확률이나 개설 보장이 아닙니다.
- 교수명·정원·신청 현황·개별 학생 수강 이력·인사 사건 추론·공식 대체과목 판정은 포함하지 않습니다.

## 3. 현재 코드와 다음 작업

| 기능 | 상태 |
|---|---|
| 기존 공지·달력 및 강의검색 화면 | 구현됨, 자료 미연결 |
| `js/academic/core/search/` | 이전 한국어 검색 알고리즘에서 메타데이터 검색 부분 복원, 화면 미연결 |
| `js/academic/core/forecast/offering-history.mjs` | 이전 개설 이력 집계 부분 복원, 화면 미연결 |
| 출처 URL 구분·공지 제목 주제 분류·정규 JSON 해시 | 기존 순수 함수 복원, 실제 권리 승인이나 검수 증명은 아님 |
| 수집 금지기간·실행 차단 | 기존 스크립트 복원, 실제 크롤러는 없음 |
| 공개 데이터 계약·권리 및 정책판본·정정/철회·공개판 생성 | 미구현 |
| 실제 수집 예산·전역 잠금·오류 당일 차단 | 미구현 |
| 실제 데이터 연결·검색/달력/집계 UI 통합 | 미구현, 메뉴 및 자료 연결 OFF |

기존 읽기 어댑터의 구형 교수명·FAQ·Supabase 연결 계약은 제거했습니다. 새 계약과 검수·철회 경계가 구현되기 전에는 활성 설정을 거부합니다. 복원한 내부 모듈은 공개 빌드 허용 목록에 추가하지 않았으며 실제 학교 데이터는 받지 않습니다.

## 4. 자료 수집·보존 경계

[공개자료 운영 방침](public-data-operating-decision.md)과 [직원 서면 안내](sources/2026-11-23-hufs-information-office-reply.txt)를 우선합니다. 직원 안내와 운영 해석은 학교의 공식 승인이 아닙니다. 기존에 정한 공지의 보수적 내부 예산은 게시판 1개부터 시작(최대 2개), 첫 목록만, 신규 상세 최대 10개/일, 총 12요청/일 이하, 시작 간격 최소 15초, 전역 동시 1개입니다. 최초 목록은 기준선으로만 기록하고 기존 상세 백필과 누락분 재수집은 하지 않습니다. 강의시간표는 학기당 2회 이하이며 학교 안내의 모든 상한·금지일·오류 차단을 지켜야 합니다.

현재 `mode: disabled`이고 다른 수강신청·정정 기간도 미확인입니다. `npm run collection:gate`는 수집 예산 및 실행 기능이 미구현인 상태에서 실행을 항상 거부합니다. 실제 수집·DB·자료 공개는 별도 승인 전까지 시작하지 않습니다.

## 5. 최소 검증

`npm run test:academic`은 합성 검색·개설 집계, 미연결 및 금지 설정, 공개 데이터 경계와 날짜 차단만 검사합니다. 이전 전면 UI 동결·Windows 브라우저 QA·연구 과제별 테스트 체계는 복원하지 않습니다.
