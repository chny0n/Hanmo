## 결함과 수정

- **P1 배포 자산 개인정보 최소화:** 기준 산출물의 고정 JPEG에 촬영 장비 식별 메타데이터가 포함됐다. 스테이징에서 해당 EXIF 세그먼트만 제외하고 압축 스캔과 색상 프로필 및 추적 원본은 보존한다. 합성 세그먼트 회귀와 실제 스테이징·로컬 응답을 검사했다. 동일 디코딩 RGB 픽셀을 별도 비교했다. **공개 Git의 원본/이력, 기존 아티팩트, 제3자 캐시 삭제를 의미하지 않는다.** 추적 원본 변경·이력 수정은 기존 보호/승인 절차를 따로 검토한다.
- **P1 시간대 의존 QA:** 기존 연습 제한 시간에는 실제 연습 경로 대신 모드 선택 페이지의 공통 요소를 검사하거나 시나리오가 시작되지 않을 수 있었다. 테스트 시계를 KST의 허용 시각에 고정하고 대상 URL을 확인하며, 이용 제한 자체와 타이머 회귀는 계속 검사한다. 원작 코드는 그대로다.
- **P1 개발자 소개 검증의 공백:** 상대 크기 비교만으로는 계약의 정확한 16px/700 및 12px/400을 증명하지 못했다. 지정 폭과 1280×720에서 실제 계산 스타일, 이름·소속 순서, 세 역할 문자열, 잘림을 검증하도록 보강했다. 물리 Windows 확인은 #138에 남긴다.

수정 후보에서 보호 검사·전체 Node 검사·독립 합성 스크립트·브라우저 테스트 목록을 직접 재검사했다. 레거시 경계 테스트 추가 후 67 PASS, 사진 검증 추가 뒤 smoke의 마지막 묶음 10 PASS. 브라우저 실행은 새 커밋의 Actions에서 별도 확인한다.

## 실측 레이아웃 및 배포 증거

Windows Chrome/Edge 러너의 최대 15과목 자동 스크린샷과 [상단의 아티팩트](#직접-실행-및-동일-sha의-독립-자동화-증거)에서 같은 SELECT 좌표를 재확인했다. 세 화면 모두 문서와 푸터는 화면에 맞지만, 기존 승인 표는 내부에서 스크롤된다. 엄격한 무스크롤 조건은 **FAIL(원작 보호와 충돌)** 이며 임의 변경하지 않는다.

실제 기준 `dist` 89개 파일을 루프백 HTTP 응답과 바이트별 대조했다(89/89 일치). 삭제 경로 8개가 직접 요청에서 404, 15개 HTML에 비공식 고지 문자열이 남았다. 155개 esbuild 입력 중 저장소 출처는 승인된 7개 모듈뿐이다. GPL-3.0, Lucide 고지, 실제 번들에 기여한 패키지 5종의 고지가 있다. 정적 자산 권리나 고지의 실제 낭독까지 자동으로 증명하지 않는다.

**운영 전 확인:** UI가 동결된 별도 정적 스크립트에 구형 Supabase/교수명 코드가 남아 있지만, 현재 미리보기의 자료 설정은 비활성이고 배포에 실제 데이터나 스냅샷은 없다. 자료 연결 전 기존 구형 경로의 격리·현행 최소 계약 검수가 필요하다. 또 여섯 레거시 HTML에 외부 태그·채널 상담·폰트 로딩 선언이 있다. 이 감사에서 학교나 외부 SDK를 호출하지 않았고, 선언을 실제 학생 정보 전송의 증거로 보지 않는다.
