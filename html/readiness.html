A → B → C → D → F 순서로 처음 충족하는 기준을 적용해요. 한모의 참고 기준이며 실제 학교 서버·공식 하드웨어 벤치마크 또는 수강신청 성공률이 아니에요.

  • 긴 작업(50ms 이상): 0·1·2·3~4·5회 이상
  • 타이머 지연: 5·15·30ms 이하, 100ms 미만, 100ms 이상
  • HTTP 응답시간: 40·80·150·300ms 이하 / 초과
  • 연결 지터: 5·15·30·60ms 이하 / 초과
  • 다운로드 처리량: 10·5·2·0.5Mbps 이상 / 미만
  • 요청 실패(7회 중): 0·1·2·3~4·5회 이상
  • 네트워크 유형 추정: 4g(A), 3g(C), 2g(D), slow-2g(F)
  • 논리 코어: 8·6·4·2개 이상 / 미만
  • 기기 메모리 대략값: 8·4·2·1GB 이상 / 미만

타이머 표본 15개, HTTP 표본 3개, 연속 지터 차이 2개, 다운로드 표본 2개 미만이면 해당 등급을 보류해요. 전부 제외된 요청은 판정 보류, 일부 제외는 실패 횟수의 잠정 등급이에요. 미측정·미지원은 F가 아니에요.

B 이하 항목 개선 안내

    다운로드 처리량은 압축을 반영한 전송 본문 크기를 요청 전체 시간으로 나눈 값이에요. 브라우저 캐시와 전송 확인이 안 된 표본은 제외해요. 지터는 연속한 응답시간 차이의 중앙값이에요. 한모 관측값은 회선 속도나 학교 서버 성능과 다를 수 있어요.
