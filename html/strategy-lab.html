경쟁자 가정

경쟁자는 최대 8과목을 순서대로 신청합니다. 정원에 비해 경쟁자가 많을수록 경쟁자들도 더 일찍 신청할 가능성이 높습니다.

경쟁자가 여러 과목을 신청하는 정도는 내가 입력한 과목을 같은 경쟁자가 함께 신청하는 정도입니다. 전체 성공률은 이 정도를 달리해 조건마다 1,000회 실험한 결과입니다.

대기시간 가정

서버 혼잡 완화를 위한 대기 화면을 가정해 본인과 경쟁자 모두 과목마다 1~3초의 모의 대기시간을 적용합니다. 먼저 요청한 순서로 자리를 배정하고, 대기가 끝나야 다음 과목을 신청할 수 있습니다. 실제 학교 서버의 대기시간을 측정한 값은 아닙니다.

수식 보기

N: 입력 과목 수, Cᵢ: 과목 i 정원, Dᵢ: 경쟁자 수(본인 제외), rᵢ: 중요 순위, s: 신청 순번, b: 반복 실험 번호, M: 반복 수, π(s): s번째 신청 과목. 시간 단위는 ms입니다.

신청 행동시간과 대기시간
a = min(3000, 반응시간 중앙값 + 380) σ = round(min(1500, max(40, P90 − 중앙값))) Aᵦ,ₛ = max(460, a + σZᵦ,ₛ), Zᵦ,ₛ ∼ N(0,1) W = 1000 + floor(2001U), U ∼ Uniform(0,1)

선택·확인 여유 380ms, 최소 반응 80ms, 신청별 대기는 정수 1,000~3,000ms를 균등하게 뽑습니다. 대기시간은 본인과 경쟁자 모두에게 적용합니다.

경쟁자 구성과 과목 선택 확률
G(k) = max(maxᵢ Dᵢ, ceil(Σᵢ Dᵢ / k)), k ∈ {1, 2, 4} uᵢ = √(1 + Dᵢ/Cᵢ), u기타 = 1 P(i가 다음 신청 과목 | 남은 목록 L) = uᵢ / Σⱼ∈L uⱼ

G(k)명의 후보군에서 각 과목의 경쟁자 Dᵢ명을 중복 없이 균등 추출합니다. k는 복수 과목 신청 정도의 낮음·기본·높음 가정(1·2·4)이지 정확한 개인별 신청 과목 수는 아닙니다. 각 경쟁자의 전체 목록 길이는 배정된 과목 수부터 8까지의 균등 정수이며, 나머지는 입력 목록 밖 과목입니다. 선택 순서는 독립 균등 난수 U로 만든 −ln(U)/uᵢ의 오름차순입니다.

요청 시각과 마감 시각
Tᵦ,ₛ = t₀ + Σₕ₌₁…ₛ Aᵦ,ₕ + Σₕ₌₁…ₛ₋₁ Wᵦ,ₕ R ∼ Gamma(shape=20, scale=13.5) T경쟁자,ₛ = R + 380 + 650(s−1) + Σₕ₌₁…ₛ₋₁ W경쟁자,ₕ Hᵦ,ᵢ = 과목 i의 경쟁자 접수시각 중 Cᵢ번째로 작은 값 (Cᵢ > Dᵢ이면 ∞) Iᵦ(i,s) = 1{Tᵦ,ₛ < Hᵦ,ᵢ}

경쟁자의 최초 반응시간은 평균 270ms, 표준편차 약 60ms로 가정합니다. 이후 행동 간격은 650ms에 직전 대기시간을 더합니다. 요청 시점의 선착순 우선권을 가정하며 동시각은 보수적으로 실패 처리합니다.

추천 신청 순서의 목적함수
p̂ᵢ,ₛ = (1/M) Σᵦ₌₁…M Iᵦ(i,s), wᵢ = N − rᵢ + 1 π* = argmaxπ Σₛ₌₁…N wπ(s) · p̂π(s),ₛ 기대 가중 점수 = 100 × Σₛ₌₁…N wπ*(s) · p̂π*(s),ₛ / Σᵢ wᵢ

k=2인 조건의 표본에서 중요 순위 가중 기대점수를 최대화하는 순열을 비트마스크 동적 계획법으로 구합니다. 모든 과목의 동시 성공률 자체를 최대화하는 목적함수는 아닙니다.

전체 성공률과 평균 소요시간
P̂전체(k) = (100/M) Σᵦ₌M₊₁…2M ∏ₛ₌₁…N Iᵦ(π*(s),s) 평균 누적 대기 = (1/M) Σᵦ₌M₊₁…2M Σₛ₌₁…N Wᵦ,ₛ 평균 전체 소요 = (1/M) Σᵦ₌M₊₁…2M [t₀ + Σₛ₌₁…N (Aᵦ,ₛ + Wᵦ,ₛ)]

순서를 선정한 표본과 별도의 평가 표본에서 같은 순서의 전체 성공률을 k=1·2·4별로 계산합니다. 과목별 성공률을 독립이라고 가정해 곱하지 않습니다. 위 식의 곱은 같은 실험 회차의 성공 여부(0 또는 1)의 곱입니다. 소요시간에는 마지막 신청의 대기도 포함합니다. 모든 정원이 경쟁자 수보다 크면 모형 내 성공률은 100%입니다. 그 외 0회 성공·0회 실패는 미관측으로 표시합니다.
