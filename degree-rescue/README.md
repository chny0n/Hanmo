# 한모 학업 플래너 · 1차 정적 모듈

기준: [main 아키텍처](../docs/architecture.md). 이 PR은 **기존 한모 BASIC / TIME / SELECT 및 CNAME을 수정하지 않는** 1차 학업 모듈입니다.

## 학생에게 집중할 경험

1. **강의 개설 전망:** 과거 같은 계절의 학기별 개설 관측을 사용해 다음 학기 준비를 돕습니다. 과거 개설 비율은 미래 개설 확률이 아닙니다.
2. **학사행사·공지 시기 전망:** 반복 행사의 과거 시기 분석 코어는 있으며, 검수된 실데이터와 학생용 예측 화면은 후속 과제입니다. 학교 공식 신청기간을 추정 날짜로 대체하지 않습니다.
3. **전공별 중요공지와 출처:** 전공 선택 기반 공지 분류와 근거형 FAQ 로직을 확장하되, 원문 검수·적용 조건이 없으면 학생 적격성이나 확정 마감을 선언하지 않습니다.
4. **수강신청 위기 대응은 2차:** 기존 HTML/JavaScript 파일 수정과 원개발자 사전 승인 후 독립 구현합니다. 이 PR은 1차만 담당합니다.

## 실행·테스트

```bash
cd degree-rescue
npm install
npm run check
```

빌드 결과는 `dist/`의 정적 사이트 프리뷰로만 제공합니다. 원본의 운영 커스텀 도메인 `CNAME`은 포함하지 않으며 자동 배포하지 않습니다. `file://`로 직접 열지 말고 HTTP 정적 서버에서 확인하세요.

## 코드 보존·제외 원칙

**유지:** `src/core/academics/` 학점·전공·학번별 규정 판본 계산 보조 코어, `src/core/forecast/` 개설 전망·과거 평가, `src/core/campus-assist/` 학사행사·FAQ·근거 판정, `catalog.html` 저장된 WIS 페이지의 강의·교수 표시명 검색. 이수/전공 변경 계산은 개인 성적 일괄 로드·학교 RulePack 검수 전까지 학생용 졸업 판정이 아닙니다.

**삭제:** 학업과 무관한 경력·활동 연계 기능, 별도 학교 시스템 메뉴 미러 목록, 235개 옛 React/서버/소스 아카이브 및 이를 강제 검증하는 스크립트, 개인 이수 데이터 없이는 제공하기 어려운 교환학생 준비·What-if 화면 뷰모델(기존 순수 계산 코어는 유지). 원본 프로젝트 사본을 이 공개 PR 안에 통째로 저장하지 않습니다.

**범위 제외:** 공식 로그인·SSO, PostgreSQL·Fastify, React 런타임, 학생 CSV 원본·개인정보·학교 비밀키, 취업·경력·NCS, 독립 시간표 편집기, 2차 수강 시나리오, Supabase 실구축.

모든 `SYN-*` 예시는 합성 데이터입니다. 학교 공지·학칙·과목 이력 원본을 검수하지 않았고, HUFS One AI 팀 기여 코드의 공개 재배포 권리와 Hanmo GPL-3.0 호환성도 **병합 전에 별도 확인**해야 합니다.

## 학사공지·전공 신청 참고 페이지 (PR #4)

- `academic-timeline.html`: 캠퍼스·입학년도·전공(주/이중)과 목표 졸업학기를 명시적으로 입력해 참고 학사 공지 목록을 필터링합니다. 기본 제공 자료 10개는 **공지 제목과 게시일만** 검토한 것으로 신청·마감일은 제공하지 않습니다.
- `src/core/academic-schedule.ts`: 학교 학사사건 유형, 범위 미확인 UNKNOWN 처리, Asia/Seoul 날짜 경계, 취소·중복 격리, 학생 접수 마감과 행정부서 보고 시한을 분리하는 순수 로직.
- 14개 졸업 체크 항목은 **개인 메모**이자 보조 기능이며, 공식 졸업 사정이 아닙니다. 학교 성적표를 자동으로 불러오는 기능은 없습니다.
- 합성 D-day 시연은 모두 SYNTHETIC으로 표시하며 실제 학사 일정·신청기간을 예측하지 않습니다.
- [학사일정 학생용 계약/검증 상세](docs/ACADEMIC_GRADUATION_RELATIONSHIPS.md) 참고.

## PR #5 · 아키텍처에 맞춘 전공별 중요공지와 근거 주석

- 첫 화면은 **전공별 중요공지**와 **강의 개설 전망(관측 n학기 중 k학기)** 중심입니다. JSON 학점/시간표 진단은 접힌 고급 개발용 도구로 이동했습니다.
- 학사일정 페이지는 캠퍼스·주전공 우선 입력이며, 학번/목표 졸업학기/미충족 요건은 선택 입력입니다. 성적표를 자동으로 불러오거나 학교 로그인 요청을 하지 않습니다.
- `src/core/important-notices.ts`는 독립 검수·학생 대상·학생 신청 마감이 모두 확인된 자료만 상단에 최대 2건 고정하고, 나머지는 공식 원문 확인이 필요한 참고 후보로 구별합니다. 현행 10건 자료는 전공별 범위와 실제 마감이 미확정이라 **검수된 마감 0건이 정상**입니다.
- 카드의 '근거 주석'에는 게시 목록/원문, 자료 판본과 게시일, 출처·전공·학번·캠퍼스 검수 상태와 미확인 부분을 표시합니다.
- 독립 한모 2차 위기 대응 시나리오(마지막 과목 실패·재접속)는 원개발자 승인 후 기존 JavaScript 파일에서 구현하며, 이 PR에는 넣지 않았습니다.
- [PR 스택 정렬/제외 사항](docs/ARCHITECTURE_ALIGNMENT.md) 참고. **이번 공개 PR HEAD에서 옛 원본 235개 아카이브와 경력/선택 확장 UI 파일을 삭제**했으며, 과거 Git 커밋에 남은 자료의 공개권리 문제는 별도 검수 대상입니다.
