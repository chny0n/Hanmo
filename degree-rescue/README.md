# 한모 학업 플래너 (1차 · PC 전용)

[현행 아키텍처](../docs/architecture.md) · [이식 출처 기록](docs/PORTING_MAP.md)

한모의 BASIC/TIME/SELECT를 변경하지 않고 독립 정적 HTML/CSS·TypeScript(배포 시 JavaScript 번들)로 동작합니다. 학교 계정·Supabase·서버는 필요하지 않습니다.

## 현재 제공하는 기능

- **강의 개설 전망:** 승인 전 합성·로컬 자료의 과거 같은 학기 개설 관측 `k/n`과 관측 공백을 표시합니다. `k/n`은 미래 개설 확률이 아닙니다.
- **강의·교수 검색:** 사용자가 브라우저에서 직접 선택한 WIS 저장 HTML로만 검색하며 CSV 내보내기는 검증된 강좌 필드에 한정합니다.
- **전공별 중요공지:** 캠퍼스·주전공을 선택해 참고 공지 제목을 확인하고 출처·적용 대상·마감 검수 여부를 구별합니다. 초기 참고 10건에는 확정 학생 마감이 없습니다.
- **학업 체크:** 로컬 개인 메모와 가상 일정만 제공하며 학교가 확인한 졸업·지원 자격을 뜻하지 않습니다.

학사행사 예상 구간과 FAQ는 현재 **순수 계산·검색 코어**이며, 실데이터·학생용 최종 검증은 후속 작업입니다. 미허용 학교 자료 수집, 로그인·SSO, 학생 성적의 원격 업로드, 실시간 정원·공식 마감 확정은 제공하지 않습니다.

## 개발·검증

```bash
cd degree-rescue
npm install --ignore-scripts --no-audit --no-fund
npm run check
```

`npm run check`는 타입 검사·합성 회귀 테스트·정적 빌드·링크/접근성 스모크를 실행합니다. 결과는 `dist/`의 **로컬 프리뷰**이며 `CNAME`을 포함하거나 자동 운영 배포하지 않습니다. `file://` 대신 정적 HTTP 서버를 사용하세요.

학교 자료 사용권·출처 검수는 [#27](https://github.com/ot4562-glitch/Hanmo_develop/issues/27) 회신 이후 분리 진행합니다. 실제 코드 병합과 PC Chrome/Edge QA는 별도이며, 모든 `SYN-*` 데이터는 가상 예시입니다. 원본 한모 `LICENSE`의 GPL-3.0은 유지합니다.
