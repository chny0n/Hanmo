# 한모: 수강신청에서 졸업까지 — 학사 일정·전공 신청·졸업요건 연결

2026-11-18 · Phase 1 독립 학사일정 페이지. 과거 HUFS One AI 원본의 비실행 235개 파일은 공개 PR에서 제거하고, 실제 TypeScript 계산 코어와 합성 테스트만 남겼습니다.

## 목표와 선택한 접근

목표: 수강신청 때만 쓰는 모의연습을 넘어 학기마다 방문해 강의·전공·성적·학적·졸업 관련 의사결정을 확인하는 비공식 학업 플랫폼.

접근 A: 기존 Hanmo 수강신청 화면 수정 → 1차 원본 불변 요구를 위반해 제외.
접근 B: 외부 학사 서버·대학 SSO 연동 → GitHub Pages 정적·개인정보 경계에 맞지 않아 제외.
접근 C(선택): 기존 degree-rescue 독립 HTML 페이지와 브라우저 TypeScript 계산 엔진에 학사공지·졸업 일정 코어를 이식. 후속 실데이터 연결과 검수는 별도.

## 1. 모든 학사 사건의 연결 대상

| 분야 | 관련 공지·일정 | 학생 계획의 변화 |
|---|---|---|
| 학기 | 개강·종강·중간·기말시험·방학 | 계획 학기와 수강 가능 시점 |
| 수강 | 사전수강·본수강·정정·철회·계절학기·강의 개설/취소 | 필수/선수/대체과목과 시간표 |
| 전공 | 주전공 선언·학부 세부전공·이중전공 신규·변경·포기·부전공·전공심화 | 졸업 이수요건과 우선수강 과목 재설계 |
| 졸업 | 졸업사정·졸업신청·시험/FLEX·논문·외국어 인증·서류·학위수여 | 학점 외의 필수/대체 요건 관리 |
| 성적·학점 | 성적 공개/정정·재수강·학점포기·학점교류/편입 인정 | 이수 원장과 부족 학점 재계산 |
| 학적·등록 | 휴학·복학·재입학·등록/초과학기 | 목표 졸업 시점·학기 진도 변경 |
| 교환·국제 | 교환학생 신청·교환학점 인정·해외 교과 | 졸업 전 필수교과목 확보 및 외부 인정 |
| 학업 지원 | 학습상담·교직이수·학사부서 확인 | 유효한 교과정 및 학생별 경로 검증 |

채용·취업·진로·직업 추천/NCS 기능과 기존 시뮬레이션 실패 시나리오는 포함하지 않음.

## 2. 일정 수집과 학생별 필터 규칙

1. 출처 참고: 공식 학사공지 게시목록에서 확인한 제목·게시일은 REFERENCE_ONLY로만 사용. 모집·신청 기간은 임의 산출하지 않음.
2. 실제 날짜: 원문 검토 자료로 입력된 시작·마감/행사 일시만 사용. SOURCE_REVIEWED 문자열과 링크/확인일의 자기 선언은 독립 운영 검수가 아니며, 운영자가 승인한 신뢰 로더가 따로 확인한 자료만 높은 신뢰로 취급합니다.
3. 대상: 캠퍼스/입학년도/주전공·이중전공/졸업학기/학적이 없으면 UNKNOWN. 모르는 대상을 자동으로 제외하지 않음.
4. 미충족 졸업요건: 기존 학점·졸업 엔진의 openRequirementIdsFromAudit을 호출할 수 있도록 별도 함수 제공. UNKNOWN은 충족으로 처리 금지.
5. 마감: 학생 개인 접수 마감과 행정부서 내부 보고 마감 분리. 오직 학생 마감에만 D-day 부여. 7일 이내 긴급은 검토된 출처와 적용 대상 모두 확인된 경우에만 집계.
6. 중복: 같은 공지 ID가 여러 판본으로 나타나면 전체 보류. 취소된 공지와 기준 시각 이후 발행 공지도 별도 배제.
7. 날짜·일정: Asia/Seoul 경계로 계산하고 현재 자료만으로 가짜 마감/개설/졸업 확정을 만들지 않음.

## 3. 실제 구현 위치

- degree-rescue/src/core/academic-schedule.test.ts — 시각·전공·미확정·중복·행정 마감·합성 회귀 테스트
- degree-rescue/academic-timeline.html 및 degree-rescue/src/app/academic-timeline.ts — 정적 학생별 일정과 졸업 체크 인터페이스
- degree-rescue/data/academic-notices-reference.json — 2026-11-17 조회한 10개 학사 공지 제목·게시일 자료(마감 미확인)
- 학교 공개 원문 출처 후보는 `reference/hufs-academic-source-candidates.json`에 참고 메타데이터만 보관하며, React·서버 원본 복사본은 이 PR에 포함하지 않습니다.

## 4. 후속 단계에서 이어야 할 기능

- 대학 공식 학사력의 연도별 날짜·취소·변경판을 검수해 완전한 정적 JSON 구성
- 이중전공 신청/변경의 학번별 대상과 학과별 배정·교과정 규정 버전 확보
- 졸업원장 결과와 일정의 requirementRefs를 학생 입력 페이지에서 자동 연결
- 미이수 과목별 개설 전망, 대체과목, 선수요건, 분반 시간표 및 필요한 학기 수 연결
- 교환학생·계절학기·편입/휴복학이 목표 졸업학기와 졸업 가능 학점에 미치는 영향 재계산
- 출처 변경 감지와 공지 검수·개별 학과 공지 범위 확대. 정적 GitHub Actions 전처리는 가능한 범위지만 무검수 실데이터 배포 금지
- 일정 내보내기(예: 캘린더 파일) 및 사용자 접근성 QA. 백엔드 푸시 알림은 현재 범위 밖

## 5. 절대 하지 않을 것

기존 한모 기본 HTML/JS/CSS/연습 화면을 1차에서 수정하지 않음. 실학생 학적/성적 CSV나 학교 로그인, 로그인된 학사서비스 자동 요청, 검증되지 않은 졸업 확정, 취업/진로 기능, 출처 권리와 기여 코드 권리 확인 없는 배포를 하지 않음.

이 페이지는 출시된 학교 공식 서비스가 아니며, 학사일정 정적 자료는 자동 갱신되지 않습니다. 학생은 개별 공지 원문과 담당 학사부서에서 최종 확인해야 합니다.
